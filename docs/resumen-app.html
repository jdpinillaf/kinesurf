1 · Motor visual de etiquetado (web) NUEVO · completo

Subir/elegir video → navegar frame a frame → ver el esqueleto MediaPipe → corregir landmarks, medir ángulos, dibujar → guardar a JSON. Stack: Flask + HTML/JS vanilla + <canvas>. Sin React, sin build, sin DB.

Features existentes

FeatureDetalle
Navegación frame-a-frame◀ ▶, slider, input de nº de frame, flechas del teclado. Frame-exacto (JPEG servido on-demand).
Overlay de esqueleto33 landmarks MediaPipe dibujados encima, toggle on/off. Sigue el movimiento al avanzar.
Corregir landmark 🖐Arrastrar un punto mal detectado a su lugar. Se guarda como corrección por frame.
Ángulo manual 📐Click 3 puntos → grados (mismo arccos que las métricas Python). Para comparar contra el cálculo automático.
Dibujo libre ✏️Trazos tipo telestrator de coach, por frame. Con undo y clear-frame.
Guardar / cargar 💾Persiste todas las anotaciones a data/output/<video>_annotations.json; al reabrir el video se rehidratan.

Endpoints (backend Flask)

RutaHace
GET /api/videosLista videos en data/raw/
GET /api/meta/<v>fps, n_frames, width, height, has_landmarks (404 si falta/corrupto)
GET /api/frame/<v>/<n>JPEG del frame n — orientación-auto iPhone, cache LRU, clamp, retry .MOV
GET /api/landmarks/<v>Landmarks [n,33,4] como JSON, NaN→null, coords 0-1
GET/POST /api/annotations/<v>Carga / persiste anotaciones (rechaza body malformado con 400)

Cómo correrlo

./venv/bin/python -m webtool.server # http://127.0.0.1:5000

Estructura del motor visual

webtool/ ├── server.py Flask: videos · meta · frame · landmarks · annotations ├── frames.py FrameReader — JPEG on-demand, cache LRU, orientación-auto ├── static/ │ ├── index.html UI: selector, doble canvas, toolbar, navegación │ ├── app.js estado, navegación, overlay, 3 herramientas, guardar │ └── style.css tema oscuro └── smoke_test.md flujo de QA (validado con puppeteer)

Calidad / decisiones de diseño

  • Coords normalizadas 0-1 en todo (independiente de resolución).
  • Frame-stepping frame-exacto vía servido JPEG on-demand (no <video> HTML5 que busca por tiempo).
  • Anti-race: guard de secuencia descarta paints de frames viejos en navegación rápida.
  • iPhone .MOV: orientación-auto + retry de frame + conteo de frames clampeado a los landmarks reales (el contenedor sobre-reporta).
  • 11 tasks, cada una con review independiente (spec + calidad) + review final de toda la branch.
